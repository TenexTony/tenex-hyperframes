# 00 · Work unattended

## What it makes

An instruction to finish a local draft while you are away; paste it above another prompt.

## What to attach

Whatever the main prompt needs. This instruction needs no extra files.

## The prompt

```text
Work on the prompt below while I'm away. Choose the visual details and export a local draft MP4.

Make reasonable choices about layout, pacing, and visual style. Write a short storyboard and use it without waiting for a creative review. If the prompt below asks for storyboard or preview approval, use this instruction as my approval for the draft only.

Use [your background color], [your brand colors], and [your font or "a clean bold sans-serif"]. Keep text large enough to read on a phone.

Keep supplied quotes, names, and numbers exact. Mark missing facts rather than guessing. Mark any sample data or placeholder clearly. Use the attached files first. Use text in place of a missing logo or photo.

Save NOTES.md in the video project with your assumptions, missing inputs, unfinished work, and anything you would improve with more time. If permissions or missing tools stop you, record the blocker instead of claiming the work is finished.

Watch the preview with sound, fix unreadable text, bad cuts, and audio glitches, then export the draft MP4. Tell me where the project, MP4, and NOTES.md are saved when you finish.
```

## Tips

- Replace its style blanks, then paste it above the main prompt in the same message.
- Use it after one successful run. It cannot approve account permissions or supply missing files.
- It allows creative review steps to be skipped for a draft. Review the MP4 yourself before sharing.
