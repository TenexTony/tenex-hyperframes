# 14 · Webinar page to promo

## What it makes

A 30-second vertical webinar invitation using details from a registration page.

## What to attach

A webinar URL. Optional: speaker photos and logo. Attach page text or screenshots if it cannot be read.

## The prompt

```text
Read [your webinar registration URL] and make a 30-second vertical promo, 9:16, for [your audience].

First extract the event name, full date, time, timezone, speakers, registration link, and what attendees will learn. Show me that list before building. If the page has conflicting details or an event date in the past, flag it. Do not invent a timezone or promote an old event as upcoming. If I am promoting a replay, label it clearly as a replay.

Use [your brand colors] and [your font or "a clean bold sans-serif"]. Use real speaker photos from my attachments or the accessible event page. If photos are unavailable, use clean name cards.

- 0–4 seconds: a specific question or problem the webinar addresses.
- 4–14 seconds: two things attendees will learn, each paired with a diagram or short example.
- 14–21 seconds: introduce the speakers with accurate names and roles.
- 21–26 seconds: show the date, time, and timezone, or the replay availability if this is a replay promo.
- 26–30 seconds: "[your call to action]", [your short display URL], and the logo or [your brand name].

Keep every key detail readable on a phone. Use only claims supported by the event page or attached brief. If the page cannot be read, use the attachments or ask for the details.

Show me the preview. After my approval, run the project checks and export an MP4.
```

## Tips

- Prompt 06 uses a brief you fill in; this one extracts details from a page.
- Confirm the timezone and whether you are promoting a live event or replay.
- Make the registration link clickable in the accompanying social post.
