# Tenex HyperFrames Prompt Pack

Free copy-paste prompts for beginners and busy professionals making videos in HyperFrames Studio.

You do not need to write code or know video editing.

## What you need

- [HyperFrames Studio](https://www.hyperframes.dev/studio) on a Mac or Linux computer. Windows is listed as coming soon.
- Claude Code or Codex connected in Studio, with an account that supports the tool you choose.
- The files listed beside your chosen prompt. A logo and your brand colors help, but you can start without them.

HyperFrames is free and open-source, and local rendering does not use HeyGen credits. Your AI account and optional generated media may have their own costs. See the [official quickstart](https://hyperframes.heygen.com/quickstart).

## Start here

1. [Set up Studio and connect your AI](guides/setup.md).
2. Open Studio and start a project. Choose one prompt below. Try the **AI clip to social post** if you already have an image or clip.
3. Attach the files listed under **What to attach**. Replace every blank in `[brackets]` with your details. If a prompt asks for a website, paste its full URL.
4. Copy only the text inside the prompt's code block. Paste it into the project's chat and send.
5. Review the proposed plan and preview when the AI asks. Give one specific correction, such as “Make the headline larger and keep it visible for two more seconds.”
6. Approve the MP4 export when you like the preview. Open the exported file and watch it with sound before sharing.

**For an unattended draft:** paste [00 · Work unattended](prompts/00-work-unattended.md) above your chosen prompt in the same message. It lets the AI choose the details and export a draft. Permission requests or missing files may still pause it.

**To revise an existing project:** prompts 07 and 09 revise an existing project. Open that project before pasting them.
